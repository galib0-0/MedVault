# MedVault
AI-powered healthcare record management platform with  multilingual report summarization, emergency doctor access,  and consent-based OTP authorization.
MedVault AI — Secure Digital Healthcare Record Management System

A full-stack healthcare platform where patients store lifelong 
medical records, doctors access them securely, and AI explains 
complex reports in plain language across 13 Indian languages.

Features:
- Unified health record vault linked to Aadhaar / MedVault ID
- AI-powered medical report summarization (Gemini API + OCR)
- Multilingual output: Telugu, Hindi, Tamil, Kannada + 9 more
- Dual portal: Patient app + Verified Doctor portal
- Emergency doctor access with 2-hour session + full audit trail
- Consent-based OTP authorization (SMS + Email + In-App)
- Pediatric profiles with parental control
- Post-access anomaly detection + Doctor Trust Score system
- Admin review queue for flagged access events

Stack: React.js · Node.js · MongoDB · PostgreSQL · AWS S3 · 
       Gemini API · Tesseract OCR · HuggingFace · IndicTrans2
